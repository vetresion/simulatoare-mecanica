Presiunea diferențială în funcție de viteză

Scară logaritmică. Punctele marcate sunt starea curentă. Pitot-Prandtl dă Δp mic, de aceea citirea pe tub U este imprecisă la viteze mici.

Curba de etalonare qv = f(Δp)

Axe logaritmice: dependența q ∝ √Δp apare ca dreaptă cu panta 1/2.

Numărul Reynolds și regimul de curgere

Ipoteze și limite ale modelului

  • Aerul este gaz ideal (R = 287.05 J/kg·K, κ = 1.4); vâscozitatea urmează legea Sutherland.
  • Densitatea se calculează la presiunea absolută din amonte, p1 = pb + ρw·g·hst.
  • Diafragma este tratată cu ecuația Reader-Harris/Gallagher cu corecția pentru D < 71.12 mm, prize la D și D/2. Conducta de 36 mm este sub limita ISO 5167-2 (D ≥ 50 mm), deci aplicarea este didactică.
  • Profilul de viteză este o lege de putere w = wmax(1 − r/R)1/n cu n ≈ 1.5·log₁₀Re, o aproximare empirică. Simularea generează citirile cu coeficienții calculați, indiferent de modul ales pentru evaluare.
  • Incertitudinea include doar citirea Δp; nu include incertitudinea coeficienților C și ε.

Cât de precis este fiecare instrument?

Debitul masic depinde de √Δp, deci eroarea relativă a debitului este jumătate din eroarea relativă a lui Δp: δq/q = ½·δ(Δp)/Δp. La un tub U fiecare diferență se obține din două citiri, deci δ(Δp) = √2·u, unde u este incertitudinea unei citiri (rezoluția din panou, minimum 0.5 mm). Senzorul piezo are ±1 Pa.
